Direção visual aprovada para a coleção: mesma família editorial de Lumyriel, com pintura narrativa texturizada, materialidade de livro antigo, tipografia clássica clara e variação de ambientes entre os volumes. Não utilizar bandeiras ou símbolos inventados como elementos de identidade visual.

As versões JPG acima são cópias leves destinadas à apresentação no site. Os originais aprovados devem ser preservados separadamente para usos editoriais de maior resolução.

## Regra de publicação

O módulo `assets/site-catalog.js` testa a existência das capas principais antes de ativá-las. Se uma arte ainda não estiver no repositório, o site mantém o placeholder atual em vez de exibir uma imagem quebrada.

As capas antigas não devem ser usadas como autoridade editorial quando houver uma das artes aprovadas acima.
